# VOXBOUND — 方块深空

《我的世界》方块画风 × 《无人深空》探索玩法的浏览器多人游戏。

## 玩法（觉醒线 · 前期还原）

1. 在陌生星球苏醒，采集**铁尘**修复扫描器  
2. 扫描定位坠毁星舰，进行系统诊断  
3. 制作**金属镀层**，从废弃建筑取得**密封环**，修复脉冲引擎  
4. 制作**双氢凝胶**，用精炼机炼出**纯铁**，修复发射推进器  
5. 升空进入太空，飞向邻近行星  
6. 俯冲时触发**大气层进入动画**（无人深空热浪 + 方块粒子）

## 操作

| 键位 | 功能 |
|------|------|
| WASD | 移动 / 飞行 |
| 鼠标 | 视角 |
| 左键 | 开采方块 |
| E | 交互 |
| F | 进入/离开星舰 |
| R | 扫描 |
| C | 制作 |
| Tab | 背包 |
| Q | 用钠充能防护 |
| Space | 跳跃 / 喷气 / 升空 |
| Shift | 冲刺 / 脉冲加速 |

## 运行

```bash
cd game
npm install
npm run dev
```

- 游戏：http://localhost:5173  
- 多人 WebSocket：`localhost:3001/ws`（由 `npm run dev` 同时启动）

## 技术

- Three.js 体素地形 + 方块星舰/行星建模  
- Web Audio 程序化音效（开采、扫描、喷气、大气进入等）  
- WebSocket 多人同屏
