# 学习通自动刷课助手

一款用于超星学习通平台的浏览器自动刷课插件（Manifest V3）。

## 功能特性

- **自动播放视频**：检测到视频后自动播放；被浏览器拦截时降级为静音播放，并尝试点击播放按钮
- **倍速调节**：支持 0.5x - 4x，播放器改回倍速时会自动纠正
- **静音播放**：默认开启，提高自动播放成功率
- **自动答题**：视频内弹窗题随机作答并提交（仅用于跳过弹窗）
- **跳过章节测验**：遇到测验步骤可自动进入下一节
- **自动切换章节**：视频结束 / 任务点完成 / 文档读完后，通过下一节按钮或课程目录继续
- **步骤页签识别**：停在"学习目标"等步骤时，自动切到"视频"页签
- **文档阅读**：对文档类任务点自动滚动，推进阅读进度
- **卡顿恢复**：播放进度长时间不动时自动尝试恢复
- **页面状态浮层**：课程页右下角显示运行状态与进度
- **设置即时生效**：弹窗中修改设置后立即同步到所有页面，无需点保存、无需刷新
- **iframe 支持**：学习通视频位于嵌套 iframe 中，插件会注入所有 frame

## 安装步骤

### Chrome / Edge 浏览器

1. 下载本项目文件夹到本地
2. 打开浏览器，访问 `chrome://extensions/`（Edge 用户访问 `edge://extensions/`）
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本项目文件夹

### Firefox 浏览器

1. 打开 Firefox（115 及以上版本），访问 `about:debugging#/runtime/this-firefox`
2. 点击"临时加载附加组件"
3. 选择项目文件夹中的 `manifest.json` 文件

## 使用方法

1. 安装插件后，浏览器工具栏会出现插件图标
2. 打开学习通课程**播放页**（带左侧目录的页面）
3. 插件会自动开始工作；也可点击图标调整设置
4. 页面右下角可看到运行状态浮层
5. 设置修改后立即生效

## 配置选项

| 选项 | 说明 | 默认 |
| --- | --- | --- |
| 开启自动刷课 | 播放、续播、切章总开关 | 开 |
| 自动答题 | 视频弹窗题随机作答 | 开 |
| 静音播放 | 静音以提高自动播放成功率 | 开 |
| 跳过章节测验 | 测验页自动进下一节 | 开 |
| 自动下一节 | 视频/任务完成后继续 | 开 |
| 播放倍速 | 0.5x - 4x | 1.5x |

## 注意事项

1. 部分课程有防刷机制，倍速过高可能被判定学时无效，建议 1.5x - 2x
2. 自动答题为随机选择，可能答错；重要考核题请手动作答
3. 若浏览器完全禁止自动播放，首次可手动点击一次播放，之后插件会接管
4. 章节测验"跳过"只是进入下一学习步骤，不会替你完成测验得分
5. 请遵守学校和平台相关规定，本插件仅供学习交流使用

```
├── shared/defaults.js      # 共享默认配置
├── icons/                  # PNG 图标
├── scripts/generate_icons.py
├── tests/                  # 端到端测试
│   ├── mock-server.js
│   ├── e2e.js
│   └── run.js
├── package.json
└── README.md
```

## 开发与测试

```bash
# 安装测试依赖并准备 Chromium / 测试视频
npm install
npm run test:prepare

# 运行端到端测试
npm test
```

测试会验证：扩展加载、iframe 视频接管、默认倍速/静音、页签切换、状态浮层、弹窗即时改速、测验跳过、自动答题。

重新生成图标：

```bash
pip install pillow && python3 scripts/generate_icons.py
```
