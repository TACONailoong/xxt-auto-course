# 学习通自动刷课助手

一款用于超星学习通平台的浏览器自动刷课插件（Manifest V3）。

## 功能特性

- **自动播放视频**：检测到视频后自动开始播放（被浏览器自动播放策略拦截时自动降级为静音播放）
- **倍速调节**：支持 0.5x - 4x 播放速度调节，播放器改回倍速时会自动纠正
- **自动答题**：检测到视频内答题弹窗时自动随机选择答案并提交
- **自动切换章节**：视频播放完成后自动进入下一章节
- **自动续播**：视频被意外暂停时自动恢复播放
- **设置实时生效**：在弹窗中保存设置后，所有已打开的课程页面立即应用，无需刷新
- **iframe 支持**：学习通视频位于嵌套 iframe 中，插件会注入所有 frame 正常工作

## 安装步骤

### Chrome / Edge 浏览器

1. 下载本项目文件夹到本地
2. 打开浏览器，访问 `chrome://extensions/`（Edge 用户访问 `edge://extensions/`）
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本项目文件夹

### Firefox 浏览器

1. 打开 Firefox（115 及以上版本），访问 `about:debugging#/runtime/this-firefox`
2. 点击"临时加载附加组件"
3. 选择项目文件夹中的 `manifest.json` 文件

## 使用方法

1. 安装插件后，浏览器工具栏会出现插件图标
2. 打开学习通课程页面
3. 点击插件图标，打开控制面板
4. 开启"自动刷课"开关
5. 调节适合的播放倍速
6. 点击"保存设置"，设置会立即在课程页面生效

## 配置选项

- **自动刷课**：开启/关闭自动播放、自动续播和章节切换
- **自动答题**：开启/关闭自动答题功能（答案为随机选择，仅用于跳过弹窗）
- **播放倍速**：调节视频播放速度，建议 1.5x - 2x

## 注意事项

1. 部分课程可能有防刷机制，倍速过高可能被平台判定学时无效，建议 1.5x - 2x
2. 自动答题为随机选择，可能答错，重要考核题请手动作答
3. 若浏览器完全禁止自动播放，首次需手动点击一次播放，之后插件会自动接管
4. 请遵守学校和平台的相关规定，本插件仅供学习交流使用

## 文件结构

```
├── manifest.json      # 插件配置文件（Manifest V3）
├── content.js         # 内容脚本（注入到页面及所有 iframe）
├── background.js      # 背景脚本（初始化默认配置）
├── popup.html         # 弹出界面
├── popup.js           # 弹出界面逻辑
├── icons/             # PNG 图标（16 / 48 / 128）
├── scripts/
│   └── generate_icons.py  # 图标生成脚本（需要 Pillow）
└── README.md          # 说明文档
```

## 开发说明

- 弹窗页面不使用内联脚本/内联事件，符合 MV3 内容安全策略
- 设置通过 `chrome.storage.sync` 存储，内容脚本监听 `storage.onChanged` 实时同步
- 重新生成图标：`pip install pillow && python3 scripts/generate_icons.py`
