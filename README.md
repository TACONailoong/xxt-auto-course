# 学习通自动刷课助手

一款用于超星学习通平台的浏览器自动刷课插件。

## 功能特性

- **自动播放视频**：检测到视频后自动开始播放
- **倍速调节**：支持 0.5x - 4x 播放速度调节
- **多种答题模式**：
  - 随机答题：随机选择答案
  - 题库答题：基于本地题库关键词匹配
  - AI 答题：调用 AI API 智能答题
- **自动切换章节**：视频播放完成后自动进入下一章节
- **友好的控制界面**：简洁美观的弹出面板

## 安装步骤

### Chrome / Edge 浏览器

1. 下载插件文件夹到本地
2. 打开浏览器，访问 `chrome://extensions/`（Edge 用户访问 `edge://extensions/`）
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择插件文件夹

### Firefox 浏览器

1. 打开 Firefox，访问 `about:debugging#/runtime/this-firefox`
2. 点击"临时加载附加组件"
3. 选择插件文件夹中的 `manifest.json` 文件

## 使用方法

1. 安装插件后，浏览器工具栏会出现插件图标
2. 打开学习通课程页面
3. 点击插件图标，打开控制面板
4. 开启"自动刷课"开关
5. 调节适合的播放倍速
6. 选择答题模式（随机/题库/AI）
7. 如使用 AI 答题模式，配置 AI API 地址和密钥
8. 点击"保存设置"

插件将自动开始工作！

## 配置选项

- **自动刷课**：开启/关闭自动播放功能
- **答题模式**：选择自动答题的策略
  - 随机：随机选择答案，适用于无题库的情况
  - 题库：基于本地题库进行关键词匹配答题，准确率更高
  - AI：调用 AI API（如 OpenAI）进行智能答题，需要配置 API 地址和密钥
- **播放倍速**：调节视频播放速度，建议 1.5x - 2x
- **AI API 配置**（仅 AI 答题模式）：
  - API 地址：OpenAI 兼容的 API 端点
  - API 密钥：用于身份验证的密钥

## 注意事项

1. 部分课程可能有防刷机制，建议使用正常倍速
2. 自动答题功能仅供参考，可能会答错
3. AI 答题需要有效的 API 密钥，可能产生费用
4. 题库答题依赖关键词匹配，准确率取决于题库覆盖范围
5. 请遵守学校和平台的相关规定
6. 本插件仅供学习交流使用

```
├── popup.html         # 弹出界面

├── icons/             # 图标文件夹
│   ├── icon16.svg
│   ├── icon48.svg
│   └── icon128.svg
└── README.md          # 说明文档
```

## 图标说明

插件提供了 SVG 格式的图标文件。如需使用 PNG 格式：
1. 将 SVG 图标转换为 PNG（建议尺寸：16x16, 48x48, 128x128）
2. 将转换后的 PNG 文件放入 `icons/` 文件夹
3. 修改 `manifest.json` 中的图标路径为 `.png` 扩展名
