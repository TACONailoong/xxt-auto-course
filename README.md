# 学习通自动刷课助手

一款用于超星学习通平台的浏览器自动刷课插件（Manifest V3）。

## 功能特性

- **自动播放视频**：检测到视频后自动播放；被拦截时降级静音播放，并尝试点击播放按钮
- **倍速调节**：0.5x - 4x，播放器改回倍速时自动纠正
- **静音播放**：默认开启，提高自动播放成功率
- **自动答题**：视频弹窗题随机作答并提交（仅用于跳过弹窗）
- **防挂机提示**：自动点击“继续学习 / 我知道了”
- **跳过章节测验**：测验步骤可自动进入下一节
- **自动切换章节**：优先从课程目录进入下一未完成小节
- **步骤页签识别**：停在“学习目标”时自动切到“视频”
- **文档阅读**：文档类任务点自动滚动
- **卡顿恢复**：进度长时间不动时尝试恢复
- **状态浮层 / 弹窗**：显示当前章节、进度条、最近活动；浮层可暂停/隐藏/收起
- **浮层可拖拽**：位置与收起状态会记住；支持快捷加减倍速
- **会话统计**：时长 / 切章数 / 答题数，可一键重置
- **选项摘要**：折叠区显示当前开启能力；倍速过高有风险提示
- **恢复默认**：一键还原设置；浮层双击标题可复位位置
- **图标 badge**：运行中 `ON`，停止 `停`
- **设置即时生效**：修改后立即同步，无需保存、无需刷新
- **稳健运行**：MutationObserver 防抖、状态上报节流、扩展重载后自动停表

## 安装步骤

### Chrome / Edge

1. 下载本项目到本地
2. 打开 `chrome://extensions/`（Edge：`edge://extensions/`）
3. 开启“开发者模式”
4. 点击“加载已解压的扩展程序”
5. 选择本项目文件夹

### Firefox（115+）

1. 打开 `about:debugging#/runtime/this-firefox`
2. 点击“临时加载附加组件”
3. 选择 `manifest.json`

## 使用方法

1. 安装后打开学习通课程**播放页**
2. 插件自动工作；也可点图标调整设置
3. 右下角浮层可查看章节/进度，并暂停或隐藏
4. 设置修改后立即生效

## 配置选项

| 选项 | 说明 | 默认 |
| --- | --- | --- |
| 开启自动刷课 | 总开关 | 开 |
| 自动答题 | 弹窗题随机作答 | 开 |
| 静音播放 | 提高自动播放成功率 | 开 |
| 跳过章节测验 | 测验页自动下一节 | 开 |
| 自动下一节 | 视频/任务完成后继续 | 开 |
| 关闭防挂机提示 | 自动点继续学习 | 开 |
| 显示页面浮层 | 右下角状态面板 | 开 |
| 播放倍速 | 0.5x - 4x | 1.5x |

## 注意事项

1. 倍速过高可能被判定学时无效，建议 1.5x - 2x
2. 自动答题为随机选择；重要题请手动作答
3. 若浏览器禁止自动播放，可先手动点一次播放
4. 跳过测验不会替你完成得分
5. **不处理人脸识别**；遇到刷脸请手动完成
6. 仅供学习交流，请遵守学校与平台规定
