# 樱色日记 ～Sakura Diary～

一款可在浏览器中完整体验的**日式校园恋爱 Galgame**。

转学至樱丘学院的你，将在樱花季节里邂逅三位女孩——选择靠近谁，故事就会走向不同的结局。

## 游玩方式

1. 用本地服务器打开项目根目录（推荐）：

```bash
# Python
python3 -m http.server 8080

# 或 Node
npx --yes serve -l 8080
```

2. 浏览器访问 `http://localhost:8080`
3. 点击「开始游戏」

> 也可直接双击打开 `index.html`。若遇本地图片加载限制，请使用上方本地服务器方式。

## 操作说明

| 操作 | 说明 |
|------|------|
| 点击对话框 / 空格 / Enter | 推进对话 |
| AUTO | 自动播放 |
| SKIP | 快进至选项 |
| SAVE / LOAD | 存档 / 读档（6 栏，本地浏览器保存） |
| LOG | 对话回看 |
| MENU / Esc | 打开菜单 |
| 回忆图鉴 | 查看已解锁 CG 与场景 |

## 游戏内容

- **完整流程**：标题 → 序章公共线 → 路线分歧 → 角色线 → 多结局 → 图鉴
- **可攻略角色**
  - 樱井 美咲：开朗的班级委员
  - 月野 遥：安静的图书委员
  - 青山 凛：直率的田径部成员
- **结局**：每位角色 Good / Bad，另有 Normal（空白）结局
- **系统**：好感度、选项分歧、CG 解锁、樱花粒子与转场动效

## 项目结构

```
├── index.html          # 主页面
├── css/main.css        # 界面样式
├── js/
│   ├── story.js        # 完整剧情脚本
│   └── engine.js       # 游戏引擎（对话/存档/图鉴等）
├── assets/
│   ├── bg/             # 场景背景
│   ├── char/           # 角色立绘
│   └── cg/             # 结局 CG
└── README.md
```

## 技术说明

- 纯前端实现，无构建步骤，无后端依赖
- 进度与图鉴解锁保存在 `localStorage`
- 适配桌面与移动端浏览器
